FIELD ENGINEERING

Integration Manuals

Reference workflows for estimating and implementing secure read-only connectivity.

ControlLogix / FactoryTalk → TRACE

  1. Confirm plant owner approval, cybersecurity review, network zone and read-only data scope.
  2. Inventory controllers, firmware, chassis, IPs, Studio 5000 project revisions and requested tag list. Do not expose controllers directly to the internet.
  3. Agree on architecture: an industrial edge gateway inside the OT network reads approved tags through an authorized EtherNet/IP/CIP driver; alternatively use an existing historian or OPC UA gateway.
  4. Verify routing, firewall allowlists, least-privilege gateway access and protocol compatibility with OT staff. Never scan production PLCs indiscriminately.
  5. Map tag names, types, engineering units, scaling, quality and timestamps; handle arrays, UDTs and unavailable tags.
  6. In a test environment, read a small set of noncritical tags; validate values against Studio 5000/FactoryTalk with the operator.
  7. Configure buffering, rate limits, reconnect/backoff, clock sync and outbound encrypted transmission to TRACE; do not enable writes.
  8. Complete FAT/SAT, documented rollback, alarm/quality tests, acceptance signoff and ongoing change management.

Complexity drivers: tag count and UDTs, network segmentation, firmware compatibility, gateways, sampling rates, historical backfill, cybersecurity approvals, redundancy and multi-site scope. One PLC with 30 clean tags differs greatly from 200 PLCs across multiple plants.

Honeywell Niagara / JACE / Optimizer BMS → TRACE

  1. Obtain facility authorization, platform versions, Niagara licensing, station backup and point inventory.
  2. Identify data source: JACE station, Supervisor, Niagara histories or supported OPC UA/BACnet export. Confirm required driver licenses.
  3. Choose read-only integration at the Supervisor/approved gateway rather than direct access to each controller where possible.
  4. Map Niagara points and histories with units, status, device identity and timestamp; review polling load.
  5. Provision network segmentation, certificates and authenticated service credentials through the customer's IT/OT process; never store credentials in browser code.
  6. Test a few points and history samples against Niagara Workbench; verify stale/fault states and time zones.
  7. Expand in batches, test failure/reconnect behavior, document backups and obtain operational acceptance.

Complexity drivers: station licensing, LON/BACnet bridges, histories, point naming, multiple JACEs, legacy controllers, network boundaries and gateway availability.

Implementation sizing

Small: 1–3 PLCs or 1 BMS, one site, approved gateway and modest tag set. Medium: 4–20 PLCs or several BMS stations. Large: 21–200+ PLCs, multiple cells/sites, high tag volume, historians and extensive security/change-control work. Treat prices as scoping estimates, not guaranteed fixed bids.

Safety: production industrial systems require authorized OT/IT personnel, maintenance windows as applicable, and engineering validation. TRACE integrations should start read-only; no control commands, interlocks or safety functions are modified by these guides.
